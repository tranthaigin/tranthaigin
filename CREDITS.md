# Sources, adaptations, and licenses

This revision follows the user's requested source-based adaptation of the Nyan and Minh Duy profiles. It is not the earlier ORBIT / GIN implementation. Exact imported revisions are recorded in `vendor/sources.json`.

## Nyan's galaxy scene

Source: [nyanduong/nyanduong — svg/nyan.svg](https://github.com/nyanduong/nyanduong/blob/e994826ae45f5869f5c542f7c5d01e9fa5750068/svg/nyan.svg).

Retained and adapted: self-contained SVG `foreignObject`, embedded star-background and Earth textures, CSS background movement, globe texture scrolling, and inset-shadow spherical lighting. The original source is preserved in `vendor/nyanduong/nyan.original.svg`; extracted unmodified textures are in `textures.json`.

Changed: personal text, layout, colors, a procedural spiral-galaxy texture rotating within an inclined plane, ambient glow, Saturn-like rings, a distant blue planet, and reduced-motion CSS. This is a cinematic illustration, not a scale-accurate astronomical model. The new galaxy texture is generated by `scripts/build_galaxy_texture.py`; no astronomy photo is claimed as original.

No license file was identified in the inspected Nyan repository. The adaptation was made locally at the user's explicit request, with source attribution retained. This document does not grant a new license to the reference artwork or its embedded textures; verify permission for redistribution before public release.

## Minh Duy's pixel lettering / gitartwork

Reference: [minhduyhodev/minhduyhodev](https://github.com/minhduyhodev/minhduyhodev), particularly `.github/workflows/gitartwork.yml` and `gitartwork.svg`.

Original generator: [jasineri/gitartwork](https://github.com/jasineri/gitartwork/tree/8e30a804880ec6360e03df12a380ad0631e81f08), copyright © 2022 Nerijus Jasinskas, **BSD-3-Clause**. Full required notice and disclaimer: [licenses/gitartwork-BSD-3-Clause.txt](licenses/gitartwork-BSD-3-Clause.txt).

The inspected bundle provides a 5×7 ASCII bitmap font and bit-to-tile conversion. These are reused in `vendor/gitartwork/font5x7.json` and `scripts/build_profile.py`. Upstream truncates text to eight characters and chooses colors randomly; it does not fetch the user's calendar in the inspected entrypoint. Our adaptation removes the length restriction, spells **Tran Thai Gin**, preserves real dates/counts/levels from a GraphQL snapshot, and animates grid → scattered tiles → lettering → grid over 16 seconds. Higher-activity dates are prioritized for visible letter tiles. Remaining dates fade during the lettering phase. No commit history is generated or rewritten.

## Galaga

Both reference profiles use [abozanona/pacman-contribution-graph](https://github.com/abozanona/pacman-contribution-graph/tree/7332e1de7903ab780c3692a4127a59cc13872daa).

The checked-in readable distribution is preserved as `vendor/arcade/arcade.mjs`, with trailing whitespace normalized only. Our `scripts/render_arcade.mjs` invokes its `GalagaRenderer`, adds a responsive SVG viewBox, and supplies the real saved calendar through an offline fetch adapter. It does not execute the upstream GitHub Action entrypoint, which includes analytics/leaderboard requests. No personal token is passed to the renderer and the adapter rejects all other network requests.

No license file was identified in the inspected upstream tree/package metadata. Attribution is retained; this does not establish unrestricted redistribution permission. Upstream review and permission clarification are required before public redistribution of this vendored library.
